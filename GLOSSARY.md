# History map

Language used to describe the historical narrative presented by the history map.

## Language

**Historical period**:
A span of Babyn Yar's history presented under a shared title. A historical period
can contain several scenes.
_Avoid_: Layer when referring to a historical period.

**Scene**:
One stage of the history map narrative, presenting a map or video with accompanying
historical text. Scenes in the same historical period can present different
objects or events.
_Avoid_: Period when referring to a single stage.

**Reveal sequence**:
The order and timing in which objects appear within a scene.
